# TASS Hooks - Selenium based
## Hooks
Hooks may only be invoked during their allowed events. Attempting to invoke a hook during an unsupported event will cause an error.
### Screenshot
#### Description
Takes a screenshot of the entire viewport. Allows for optionally naming the screenshot else uses the default naming convention.
#### Available Events
- ON_SUCCESS
- ON_FAILURE
- ON_START
- ON_FINISH
